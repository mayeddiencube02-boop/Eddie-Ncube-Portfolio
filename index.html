NaijaShop: E-commerce Data Pipeline

An end-to-end pipeline that pulls data from several sources into one Neon Postgres database. These are generated customer and order data, a marketing spend Google Sheet and a daily USD to NGN exchange rate API. A layered dbt project (staging, intermediate, marts) turns it into seven tested, Power BI-ready tables, including customer 360, RFM segmentation, daily revenue, month-over-month growth and marketing performance. Runs on a daily GitHub Actions schedule, with Airbyte syncing the marketing and exchange-rate data. The image shows the dbt lineage graph, from raw tables to marts (click to enlarge).

PortfolioPulse: Investment Tracker in USD and NGN

A daily pipeline that values a six-stock portfolio (AAPL, MSFT, NVDA, AMZN, META, GOOGL) in both US dollars and Naira. Prices come from yfinance, trades from a Google Sheet through Airbyte, and exchange rates from a custom Airbyte connector I built after the original rate API went offline. dbt models with 27 tests produce daily portfolio value and gain/loss, shown on a four-chart Metabase dashboard. Orchestrated weekdays with GitHub Actions.

RetailPulse: Customer Analytics and Demand Forecasting

Zidio internship project on the Online Retail II dataset. One command runs the whole pipeline: cleaning, RFM and K-Means segmentation for 4,334 customers, a churn model (Optuna-tuned Gradient Boosting, ROC-AUC 0.75, 393 customers flagged high risk), a 30-day revenue forecast (WAPE 22.3%, slightly better than a seasonal baseline) and an inventory plan. Results feed a live Streamlit app and a four-page Power BI report, with MLflow experiment tracking.
